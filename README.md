# Projet-C-SVG
First C project which allow the user to create shapes, list which one have already been created and can be modified

## What you are able to do :
- Create a circle, an elipse, a line or a rectangle
- Modify a shape with his index
- Gives color to it's outline and background
- Visualize your SVG file

## How to use :
1. Compile the got with ***make build***
2. Run the code with ***make run***
3. Save your file and open it
4. Enjoy the result !

## What this project allowed me to do :
* Get a better knowledge of the the memory management
* Learn the fondamentals of C programming
* Understand the user/computer relation
